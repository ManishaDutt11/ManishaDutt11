### 💼 Featured Projects

#### 🎓 [Student Exam Performance Predictor](https://github.com/ManishaDutt11/ml-project)
`Python` · `Scikit-Learn` · `XGBoost` · `CatBoost` · `Ensemble Learning` · `Flask` · `Render`

An end-to-end ML pipeline — not just a notebook — built with 8+ reusable modules covering data processing, training, and inference.
- Evaluated 6+ models and shipped the best one (**R² = 0.88**) behind a Flask API returning predictions in **under 1 second**
- Cut code duplication by **60%** through modular design, structured logging, and proper exception handling
- Deployed live on Render, so it's actually usable by someone other than me

#### 📉 [Customer Churn Prediction](https://github.com/ManishaDutt11/customer_churn_project)
`Python` · `Pandas` · `Scikit-Learn` · `XGBoost` · `SHAP` · `Streamlit`

The kind of project where the business question matters as much as the model.
- Hit **92%+ accuracy** on 10,000+ customer records after EDA and feature engineering that trimmed preprocessing time by **30%**
- Went beyond accuracy — evaluated with precision/recall and ROC-AUC, then used **SHAP** to explain *why* customers were flagged as churn risks
- Wrapped it all in an interactive Streamlit dashboard for real-time prediction and retention-strategy insights

#### 🎬 [Movie Recommendation System](https://github.com/ManishaDutt11/movie_recommendation)
`Python` · `Scikit-Learn` · `NLP` · `TF-IDF` · `Cosine Similarity` · `Streamlit`

A content-based recommender that actually feels snappy to use.
- Engineered features from genre, overview, tagline, and keywords across **40,000+ TMDB movies**
- Serves top-10 similar movies in real time via TF-IDF + cosine similarity
- Built a searchable Streamlit front end with sub-1-second response time

#### 🔥 [Forest Fire Risk Prediction System] (https://github.com/ManishaDutt11/linear-regression-project)
`Python` · `NumPy` · `Pandas` · `Scikit-Learn` · `EDA` · `Regression Modeling` · `Cross-Validation`

- End-to-end FWI (Fire Weather Index) prediction system: cleaning, EDA, outlier treatment, feature scaling
- Benchmarked 4 regularized regression models (Ridge, Lasso, ElasticNet + CV variants), squeezing out a **4–5% performance gain**
